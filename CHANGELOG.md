# Changelog

All notable changes to this project are documented here. The format is based on

## [Unreleased]

### Added
- Clock in/out with break (pause/resume) via an RHS panel and `/track` slash command.
- Optional project + note per entry, with autocomplete from previously-used values.
- Today list and weekly timesheet (start, end, breaks, net hours, week total).
- Manual add/edit/delete of entries (timezone-correct, DST-safe).
- Self CSV export and admin CSV export across all users (formula-injection safe).
- Full-page **Team report** for system admins (date range, per-user filter, totals, export).
- German + English UI.
